## Suíte de paridade adicionada nesta fase

- `tests/fixtures/nexus-parity.mjs`: SQLite real e isolado, dois SKUs, peso fracionário, cliente fictício, pasta temporária e limpeza.
- `tests/nexus-parity-baseline.test.mjs`: NEX-P0-01 (pagamento misto/350g/reabertura), NEX-P0-02 (rollback), NEX-P0-03 (cancelamento), NEX-P0-04 (dois terminais) e NEX-P0-05 (UN vs KG).
- O comando canônico existente `npm test` inclui automaticamente esse arquivo por `tests/*.test.mjs`. Não há serviço pago, acesso à internet ou conta exigida para rodar os testes.
- Pipeline do projeto: `.github/workflows/qa.yml`, jobs `windows-tests` em Windows 2022/2025, além das jornadas F01–F54, E01–E12 e J01–J07.

## Comandos de execução

```sh
npm install --no-audit --no-fund
node --test tests/nexus-parity-baseline.test.mjs
npm test
npm run build
npm run test:desktop
```

**Restrição:** `test:desktop` usa Electron e requer Windows ou ambiente gráfico apropriado. Os testes de Node exigem Node.js 22 com `node:sqlite`. Para release, a execução no instalador Windows permanece obrigatória.

## Priorização sem replicar funcionalidades

1. P0: acrescentar fault injection do banco (SQLITE_BUSY/LOCKED, ENOSPC, interrupção/rollback) e concorrência de terminais/lan em casos adversos.
2. P1: FEFO/validade, lotes físicos, combos/variantes e rastreabilidade; cada feature primeiro RED, implementação, GREEN e E2E.
3. P1: relatórios por item/produtor, rateio explícito de pagamentos e filtros/períodos, preservando os relatórios agregados atuais.
4. P2: impressão térmica/etiquetas, importação CSV, fila de impressão e opcionalmente balança COM.
5. P3: updater somente sob decisão de escopo, sempre com backup, migração e rollback. Windows 7/8 não é alvo.

## Critérios de aceite desta fase

- Matriz versionada e rastreada até módulos de origem e destino.
- Dados de teste fictícios em banco temporário, sem afetar a loja.
- Testes novos executados via comando padrão quando o CI da PR for disparado.
- Nenhuma alteração no código de produção, no tema ou na política de licenças.
- Não realizar merge se os gates da PR não estiverem verdes.
